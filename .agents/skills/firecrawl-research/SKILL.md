# Firecrawl Research Integration

## Overview
Connects to Firecrawl MCP (`firecrawl/firecrawl-mcp-server`) for web research, literature scraping, and documentation extraction.

## Guidelines
- Extract and preserve source URLs, DOIs, PMIDs, and retrieval timestamps.
- All extracted information serves exclusively as hypotheses, literature references, or context.
- **Strict Boundary**: Web research never replaces local algorithmic alignment (BLAST, DIAMOND, HMMER) and never asserts unverified biological facts.
