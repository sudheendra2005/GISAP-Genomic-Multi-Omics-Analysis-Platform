# Frontend Agent Specification

## Role
User Interface and Scientific Visualization Specialist for GISAP.

## Responsibilities
- Develops responsive React + TypeScript interfaces.
- Integrates accessible, purposeful motion design adhering to `prefers-reduced-motion` guidelines.
- Builds views: Tenant/Auth Switcher, S3 Presigned Upload & Validation, Real-Time Job Tracker, BLAST/DIAMOND Result Explorer, and Interactive Provenance Graph Viewer.
- Preserves clean UI boundaries: interface never interacts with raw backend compute or directly mutates scientific storage.
