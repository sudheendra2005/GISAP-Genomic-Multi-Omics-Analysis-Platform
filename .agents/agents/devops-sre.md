# DevOps & SRE Agent Specification

## Role
Workflow Automation, Nextflow Pipeline Engineering, Benchmarking, and Reliability.

## Responsibilities
- Implements production-grade Nextflow workflows (`dna_alpha.nf`) supporting Docker and Apptainer execution profiles.
- Validates checkpointing and fault-tolerant `-resume` capability during simulated worker terminations.
- Establishes Prometheus metrics exporters for CPU, memory, S3 I/O, queue depth, and job throughput.
- Designs Tier-5 scalability and stress-testing benchmarks measuring GB/min processing and O(1) memory bounds.
- Guarantees end-to-end reproducibility of scientific environments across local, cloud, and HPC tiers.
