# Orchestrator Agent Specification

## Role
Platform Orchestrator and Cross-Agent Coordinator for GISAP.

## Responsibilities
- Coordinates the 6 specialized domain agents: Frontend, Backend, Bioinformatics, Infrastructure, Security, and DevOps/SRE.
- Enforces the 15 GISAP Architectural Principles and 14-layer stack boundaries.
- Blocks unauthorized architecture changes and unapproved dependencies.
- Validates end-to-end Definition of Done (DoD) across all implementation phases.
- Mediates data contracts between backend services, Nextflow workflows, and analytical storage.
